## 操作画面の対応

| 順序 | 画像ファイル名 | 画面の説明 | 学生の操作 |
|---|---|---|---|
| 1 | `01-create-codespace.png` | GitHubの **Code → Codespaces** | **Create codespace on main** を選ぶ |
| 2 | `02-trust-workspace.png` | フォルダの作成者を信頼するか | 自分のリポジトリを確認してから **フォルダーを信頼して続行** |
| 3 | `03-copilot-review.png` | Copilotの修正案と保持／元に戻す | 何を変えたか確認し、必要な修正だけ採用 |
| 4 | `04-source-control-unstaged.png` | Source Controlの**変更**欄 | `index.html` をクリックして差分を確認し、＋でステージ |
| 5 | `05-source-control-staged.png` | **ステージされている変更**欄 | メッセージ（例：`HTMLを変更`）を入力してコミット |
| 6 | `06-sync-push.png` | **変更の同期 1↑** | クリックしてGitHubへプッシュ／同期する |

### 注意

- **「コミット」は「プッシュ」ではありません。** `変更の同期 1↑` が出たら、まだGitHub側へ未反映です。
- **Copilotの「保持」はコミットではありません。** AIの変更を採用した後、Source Controlで差分確認・コミット・プッシュが必要です。
- ワークスペースの信頼は、自分が管理しているリポジトリなど、安全性を確認できるフォルダに限ります。
- GitHubのUIは更新されるため、ボタン名や画面配置が少し異なる場合があります。
